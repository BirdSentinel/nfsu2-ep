CUSTOM TRACK BILLBOARDS

Replace or edit the PNG files in this folder, keeping their filenames.
Completely close and restart Egyuttparkolas.exe to reload your images.

Keep each image's aspect ratio and preferably its original dimensions.
The game uses the original texture dimensions and UV layout. Some images
contain several signs or panels: keep those regions in the same positions.
Transparency is supported. If a PNG is missing or cannot be decoded, the
game uses its original texture instead.

OLD_SPICE files are the four original Old Spice adverts. Other filenames
identify Burger King, Cingular, AutoZone, Campbell's, Pontiac and more.
The final hexadecimal identifiers distinguish different versions of a sign;
do not remove them. BESTBUY has separate regional versions (Best Buy/Sololar).
The same texture may appear on several signs around the city: replacing its
PNG changes all those instances. These are local visual replacements.

Original PNGs were exported directly from the game's textures. Editing them
does not alter the original game archives.
