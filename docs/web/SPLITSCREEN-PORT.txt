Architecture
------------
One lifted game engine, one physics world and six independent local players.
Derived from the MIT NFSU2-SplitScreen-main source (copyright 2026 mihaits);
license retained in licenses/NFSU2-SplitScreen.txt. The ASI's x86 patch writes
are translated into static operand relocations, function overrides and hooks.

runtime/splitscreen.c ports player creation, input conversion, private cameras,
HUD packages, viewports, streaming zones/pools, settings mirrors, rumble state
bounds, pause ownership and multiplayer finish/catch-up rules. The original
NUM_PLAYERS remains two; separate relocated arrays hold the six actual players.
tools/split_reloc.py handles operand-specific relocation and capacity changes.

The browser input mailbox has six independent seqlocked records. Controllers
claim seats on Start and release joining buttons before driving. The WebGPU
protocol carries per-draw viewports and region clears preserve adjacent views.

Current menu flow
-----------------
Main Menu > Split Screen > native icon carousel (2 / 3 / 4 Players) >
Mode > Track > Race Options > Player 1 Start / Car / Transmission >
Player 2 Start / Car / Transmission > remaining players > Race.
Quick Race stays single-player. The count submenu reuses the main carousel
and the console Split Screen icon. Each seat retains its own car and gearbox.
The Windows launcher uses localPlayers=2 to enable local input and offline
network settings; the actual count is chosen in the native game menu.
The count carousel handles keyboard Escape and controller B as Back. Its native
position bar uses the active carousel's range and explicit track/thumb opacity,
including after returning to the main menu. split_count_back.txt checks
all three positions, both Back inputs, reopening and continuing with four.
Back from split-screen mode selection waits for native setup cleanup, then
reopens player-count selection with the previous count highlighted. A second
Back returns to the main menu. split_mode_back.txt covers Escape, controller B
and changing the count before re-entering mode selection. Starting a race clears
this pending setup return so quitting a race still reaches the main menu.
The count screen uses the native S_GROUP INIT entrance fade. Initial entry
is applied on the next frontend tick, after Accept queues its parent exit,
so the content swap and entrance happen together. Returning from mode setup
and returning to main play the same entrance once; the old two-tick reveal
restart is removed. split_menu_fade.txt captures early and settled frames.
Player count uses the Quick Race heading (left alignment, 0.8 scale), hides
the main-menu logo, and exposes native Back/Continue help buttons. These
properties are restored when leaving the selector. Intercepted Accept/Back
actions use IconScrollerMenu event slots 8/10 and its current sound style,
through the original frontend sound manager (confirm 4 / back 5).
Outrun is capped at two. The shared-engine arrays retain six-seat capacity;
the requested public menu exposes two, three and four players.
Each viewport now has an independently centered minimap in its lower-left
corner. Local racers keep the same green/red/blue/yellow/purple/cyan colors
on every map, including clamped edge markers for distant cars. Per-pad
vibration is not implemented.

Per-player minimaps
------------------
runtime/split_minimap.inc ports the ASI's native map snapshots and extra car
entities. The manager updates once for each local car, snapshots FE data, and
renders each map in its cell. Map groups keep a neutral parent transform so
cached FE matrices cannot move another player's map. Extra car entities are
detached before their cloned HUD packages are destroyed or the map is rebuilt.
The distance filter exempts local racers while retaining native edge clamping.
Player arrows follow native HUD visibility, including pause-menu hiding.
tests/web/scripts/split_minimap_{two,three,four}.txt exercise the layouts,
independent input and two-/three-player restarts. Set env=NFSU2_SPLIT_MAP_TEST=1:
0xd0d000 reports map count; 0xd0d010..24 report the actual player-marker draw
mask for each map. These diagnostics are disabled in ordinary play.

Rebuild and repeat tests
-----------------------
Sync changed files to the WSL copy. Regenerate after changing overrides,
HOOK_SITE addresses or the lifter:
  bash web/gen.sh '/mnt/c/Games/Need for Speed Underground 2/SPEED2.EXE'
  J=8 bash web/build.sh
  cd web && npm run check && npm run build

Start the local development server with --dev and --artifacts, then use:
  ?save=split-menu-test&env=NOMOVIES=1&env=NFSU2_NET=off&env=NFSU2_FNG_LOG=1&script=/tests/web/scripts/split_menu_four.txt&artifacts=/artifacts/

Current acceptance scripts are split_menu_two.txt, split_menu_three.txt,
split_menu_four.txt and split_menu_single.txt. Count, separate ride types and
per-seat throttles are asserted. The two-player script also exercises Back.
The earlier split_two/six/finish scripts document pre-menu engine validation;
their old Quick Race entry path predates this separate Split Screen menu.
